# irongut/CodeCoverageSummary

A GitHub Action that reads Cobertura format code coverage files and outputs a text or markdown summary.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/irongut/CodeCoverageSummary](https://github.com/irongut/CodeCoverageSummary).
